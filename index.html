Course lookup

!course 198:111 returns prerequisites, core requirements, sections, instructors and meeting times from the Rutgers Schedule of Classes API. The first lookup for a subject downloads the catalog once. After that, replies come straight from memory with no network call: a Go map behind a sync.RWMutex, refreshed every 24 hours. If one Rutgers endpoint is down, it falls back to a second.
